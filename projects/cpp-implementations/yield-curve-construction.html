Overview

The yield curve is a core concept in fixed income: it relates the interest rate (yield) to different maturities. It's essential for pricing bonds, interest rate derivatives, and for risk management. Yield curve construction turns a set of market instrument prices (deposits, swaps, government bonds) into a smooth curve of zero-coupon yields (spot rates).

Theory and Methodology

Two main steps are involved:

  1. Bootstrapping: Extracting zero-coupon rates from traded securities, recursively.
  2. Interpolation: Estimating yields at maturities where no instrument is quoted (for smoothness).

Bootstrapping the Zero-Coupon Curve

Zero-coupon bonds: The spot rate \( r \) for maturity \( T \) is derived from its price \( P \) and face value \( F \):

\[ P = \frac{F}{(1 + r)^T} \quad \implies \quad r = \left(\frac{F}{P}\right)^{1/T} - 1 \]

Coupon bonds: More complex, as each cashflow is discounted using the corresponding (already bootstrapped) spot rates. For a bond with coupon \( C \), maturity \( T \):

\[ P = \sum_{i=1}^{T-1} \frac{C}{(1 + r_i)^i} + \frac{F + C}{(1 + r_T)^T} \]

The final unknown rate \( r_T \) can be solved numerically (often using root-finding) if not in closed-form.

Intricacies and Practical Details

  • Day count conventions: Actual/Actual, 30/360, etc., affect cashflow timing and rate calculation.
  • Instrument choice: Short end: deposits/OIS; middle: futures; long end: swaps/bonds.
  • Curve smoothness: Interpolation (linear, cubic spline, Nelson-Siegel, etc.) ensures arbitrage-free, smooth curves.
  • Multiple curves: Since the 2008 crisis, separate discount and forward rate curves (OIS discounting, LIBOR/EURIBOR forwards) are common in practice.

C++ Implementation: Yield Curve Bootstrapping

Below is the C++ code used to bootstrap spot rates from fixed-coupon bond prices. This version outputs the results to a CSV file for further analysis and visualization. 

#include <iostream>
#include <vector>
#include <cmath>
#include <fstream>
#include <iomanip>

double bootstrapSpot(int idx, const std::vector<double>& prices,
                     const std::vector<double>& coupons,
                     const std::vector<double>& spots,
                     double face) {
    double sum = 0.0;
    for (int j = 0; j < idx; ++j)
        sum += coupons[idx] / std::pow(1 + spots[j], j + 1);
    double numer = coupons[idx] + face;
    double denom = prices[idx] - sum;
    return std::pow(numer / denom, 1.0 / (idx + 1)) - 1.0;
}

int main() {
    std::vector<double> prices  = {98.0, 95.0, 92.0, 89.0, 86.0};
    std::vector<double> coupons = {2.0, 2.5, 3.0, 3.2, 3.5};
    double face = 100.0;
    std::vector<double> spots;

    std::ofstream out("spot_rates.csv");
    out << "Year,SpotRate\n";

    for (size_t i = 0; i < prices.size(); ++i) {
        double spot = bootstrapSpot(i, prices, coupons, spots, face);
        spots.push_back(spot);
        out << (i + 1) << "," << std::fixed << std::setprecision(6) << spot * 100 << "\n";
        std::cout << "Year " << (i + 1) << ": Spot rate = " << spot * 100 << "%\n";
    }

    out.close();
    return 0;
}

This approach assumes annual coupons and simple yield conventions, but can be extended to semi-annual, different day-counts, and robust root-finding for more complex cashflows. The output CSV can be used for plotting and animation.

Interpolation Methods

Bootstrapping only yields spot rates at quoted maturities. For other maturities, interpolation is required.

  • Linear interpolation (on yields or discount factors): simplest, not always smooth.
  • Cubic spline interpolation: Smooths out "kinks"; widely used in quant libraries (e.g., QuantLib).
  • Parametric models: Nelson-Siegel, Svensson forms fit a smooth parametric function to the observed rates.
Practical tip: For real production code, use robust C++ libraries like QuantLib for full day count, business calendar, and robust curve construction.
