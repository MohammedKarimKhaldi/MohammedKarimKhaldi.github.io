# Financial Mathematics Projects Website

A minimalist, multi-page static website to showcase financial mathematics projects.

## Structure
- `index.html`: Home page
- `projects.html`: Projects showcase
- `about.html`: About the author
- `contact.html`: Contact information
- `assets/style.css`: Custom minimalist CSS

## Usage
- Edit the HTML files to add your own content and projects.
- Update the email in `contact.html`.
- Deploy to GitHub Pages by pushing to your repository's `main` or `gh-pages` branch.
